# Security Policy

## Supported versions / نسخه‌های پشتیبانی‌شده

فقط شاخه اصلی این ریپو پشتیبانی امنیتی دارد.

Only the main branch of this repository receives security updates.

## Reporting a vulnerability / گزارش آسیب‌پذیری

این پروژه اختصاصی است. آسیب‌پذیری را در Issue عمومی GitHub ثبت نکنید.

This project is proprietary. Do not open a public GitHub issue for a vulnerability.

به مالک ریپو از طریق GitHub (با پیام خصوصی / Security advisory در صورت فعال بودن) اطلاع دهید:

Contact the repository owner through GitHub (private message, or a private security advisory if enabled):

- GitHub: [ahmadreza-log](https://github.com/ahmadreza-log)

لطفاً این موارد را بفرستید / Please include:

1. شرح مشکل / a description of the issue
2. مراحل بازتولید / steps to reproduce
3. اثر احتمالی / potential impact
4. در صورت وجود، پیشنهاد رفع / a suggested fix, if you have one

گزارش‌های معتبر بررسی می‌شوند. تا زمان رفع مشکل، جزئیات را عمومی نکنید.

Valid reports will be reviewed. Do not disclose details publicly until a fix is released.
