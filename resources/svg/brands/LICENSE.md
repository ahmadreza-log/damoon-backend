# Brand icons

The `brand` Blade Icons set, registered in `App\Providers\AppServiceProvider`.

- Every icon except `linkedin.svg` comes from [mrdindar/blade-iranian-brands-icons](https://github.com/rezadindar/blade-iranian-brands-icons). The files are copied here because that package does not allow Laravel 13 yet.
- `linkedin.svg` comes from [Bootstrap Icons](https://github.com/twbs/icons), since Simple Icons no longer ships LinkedIn.
